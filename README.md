# Анастасия Бурашова — демонстрация сайта психолога

Статический сайт на русском языке: адаптивная главная, настоящая фотография специалиста, профессиональная история, форматы и стоимость, отзывы с источниками, FAQ, демонстрационная запись и кабинет администратора.

## Посмотреть

- Сайт: https://shanation6.github.io/anastasia-burashova-demo/
- Демо-вход: https://shanation6.github.io/anastasia-burashova-demo/admin/login.html
- Логин: `admin`
- **Публичный демонстрационный пароль:** `Demo!Burashova-2026#Green`

Это не рабочая система записи. Пароль включён в публичный клиентский код исключительно для показа интерфейса и не является защитой данных. На странице входа есть кнопка подстановки демо-доступа.

## Что можно показать заказчику

1. Открыть главную и выбрать формат консультации.
2. Заполнить форму вымышленными данными (`demo@example.com`) и подтвердить условия демонстрации.
3. Перейти в кабинет, подставить демо-доступ и войти.
4. Найти новую заявку, изменить статус, применить фильтры, удалить запись или сбросить примеры.

Заявки хранятся **только в localStorage текущего браузера**. Никакой отправки психологу, общего серверного хранилища, оплаты или резервирования времени нет. Демо-вход хранится в sessionStorage до четырёх часов. Реальные персональные данные вводить не следует. Для производственного сайта нужен отдельный сервер и настоящая аутентификация.

## Локальный запуск и проверка

Требуются Node.js 24+ и Python 3. Для самого сайта и основных тестов установка зависимостей не нужна.

```sh
npm test
python -m http.server 4173 --directory site
```

Открыть http://localhost:4173/. В PowerShell с ограниченной ExecutionPolicy используйте `npm.cmd test`.

Для браузерных проверок: `npm ci`, затем `npm run test:e2e`. На Windows тесты используют установленный Microsoft Edge; на других системах предварительно выполните `npx playwright install chromium`. Проверяются ширины 320, 390, 768 и 1440 пикселей, запись, валидация, вход, статусы, удаление, выход, клавиатурное меню, отключённое хранилище и безопасный вывод текста заявок. Тестовый сервер размещает сайт по пути `/site/`, проверяя работу относительных ссылок в подпапке.

## Публикация

GitHub Actions проверяет поведение демо и публикует папку [site](./site/) через GitHub Pages при отправке в `main`. В настройках репозитория Pages выбран источник **GitHub Actions**. Все внутренние ссылки относительные, сайт поддерживает размещение в подпапке репозитория.

## Обновлённая арт-дирекция и анимация

Публичная страница использует отдельную [редакционную стилизацию](./site/assets/editorial.css) и [модуль прогрессивного улучшения](./site/assets/motion.mjs). При переработке изучены [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) и навыки [baseline-ui](https://github.com/ibelick/ui-skills/blob/main/skills/baseline-ui/SKILL.md), [fixing-motion-performance](https://github.com/ibelick/ui-skills/blob/main/skills/fixing-motion-performance/SKILL.md) из UI Skills. Существующий стек HTML/CSS/ES-модулей сохранён.

Анимации управляются CSS: последовательное раскрытие заголовка и разделов, небольшие орнаменты, нативный индикатор чтения и scroll/view timelines в поддерживающих браузерах. Нет перехвата прокрутки, обработчика `scroll` или бесконечного JS-цикла. Орнаменты останавливаются вне экрана и при скрытии вкладки. Кнопка паузы в шапке отключает движение; системный `prefers-reduced-motion` показывает статическую композицию. Без JavaScript содержание остаётся видимым.


В [концепции](./docs/superpowers/specs/2026-10-26-psychologist-site-design.md) сохранено уточнение заказчика о демонстрации, которое заменяет первоначально предложенную серверную реализацию.
